设置配置

使用全局和项目级设置以及环境变量配置Claude Code

Claude Code 提供各种设置来配置其行为已满足您的需求。你可以通过在使用交互式REPL时运行/config 命令来配置Claude Code

设置文件

settings.json文件是我们通过分层设置配置 Claude Code 的官方机制：

  • 用户设置--在~/.claude/settings.json中定义，适用于所有项目
  • 项目设置-保存在您的项目目录中
    • .claude/settings.json 用于检入源代码控制并与团队共享的设置
    • .claude/settings.local.json 用于不检入的设置，对个人偏好和实现很有用。Claude Code会在创建时候配置git忽略.claude/settings.local.json
  • 对于Claude Code 的企业部署，我们还支持企业管理策略设置。这些设置优先于用户和项目设置。系统管理员可以将策略部署到：
    • macOS：/Library/Application Support/ClaudeCode/managed-settings.json
    • Linux 和 WSL：/etc/claude-code/managed-settings.json
    • Windows：C:\ProgramData\ClaudeCode\managed-settings.json

掌握 .claude/ 目录：让 Claude Code 真正懂你的项目

Claude Code 开箱即用已经很强大了，但真正让它如虎添翼的，是学会配置.claude/目录。这个目录是你与Claude之间的"约定"--项目规范、自定义工具、工作流自动化，全部在这里

目录结构总览

your-project/
├── .claude/
│   ├── settings.json          # 权限、MCP、环境变量配置
│   ├── settings.local.json    # 本地私有配置（不提交 git）
│   ├── rules/                 # 自动加载的规则文件（补充 CLAUDE.md）
│   │   ├── security.md
│   │   └── style.md
│   ├── commands/              # 斜杠命令（简单指令）
│   │   ├── commit.md
│   │   └── test.md
│   └── skills/                # 斜杠命令（复杂工作流）
│       ├── review.md
│       └── deploy.md
└── CLAUDE.md                  # 项目说明书（自动加载）

布林线(Bollinger Bands)

定义

布林线，也叫布林带，英文成为BOLL；布林线与MACD、RSI、KDJ等其他技术指标一样，是股市上技术分析常用工具之一；是美国经济学家约翰.布林格设计出来的一种技术分析指标；深受投资者喜爱，但布林线本身也有很大的盲点，如果错误使用的话，除了赚不到钱，还有可能导致亏损；

原理

布林线是由统计学原理中的标准差演变而来，从而了解股价波动走势；布林线主要有三条线组成；每条线具有不同的含义，通过了解判断分享寻找最好的交易时机

  • 布林线的中轨其实就是我们所熟悉的移动平均线；就是将过去某个时间点的总和平均数，中轨平均线一般系统默认为20日月线

  • 布林线的上轨和下轨就是中轨的两倍标准差，标准差其实就是一种概率的算法

MACD这个指标可以说是家喻户晓，到了人见人爱的地步。但若要真的用好它，却不是一件简单的事情

MACD底背离

M头W底等形态

形态分析：MACD属于趋势性指标，而传统形态分析中绝大部分也都是根据趋势理论逐步总结出来的，故此从原理上来看二者有较大的共通性，这也决定了MACD底背离也可用一般的形态理论进行分析，如头肩底、双底、三底、圆弧底、平台扎底等，此类形态分析中常用的量度幅度、阻力或支持位等评判理论也可适用，顶背离则反之运用

另外，MACD指标的柱状线也可以看图形形态来研判行情

当MACD的红柱或露珠构成的图形双重顶底(即M头和W底)、三重底部等形态时候，也可以按照形态理论的研判方法来加以分析研判

看懂(W低和M顶)抄底形态

概念

w低和M顶它们是形态中占有相当重要的地位，能够基于当时行情，预测将来的走向；

它们是一种技术分析中常见的K线反转信号；底部是一w形态反转；顶部就是以M形态反转；

它们除了能够预测股价反转趋势，更厉害的就是能够预测未来股价的支撑阻力的能力

分析

W底

W低也叫双底，最为明显的是拥有双底的结构；它属于一种中后期底部的形态，一般发生在波段跌势后期，意味着股价在连续两次下跌低点同时形成的形态；

是一种重要的见底信号；当一个股价经过长期跌势末期，达到一个最低的低点，市场上一些人抄底买入，把股价往上拉形成一个v形反弹，但空方还在继续卖压，股价再度回落到前期低点附近，而看涨的人把股价再度拉上来，形成一个w形形态。
