# 黄金坑选股器完整体系

## 一、九种阶段分类

黄金坑选股器按照 N 字结构及当前所处位置，共分为 9 个阶段：

| 优先级 | 类型 | 说明 |
|---------|------|------|
| 🥇 1 | 金标（Premium Buy） | 突破 H2 + 回踩 MA60 + 筹码峰合一 |
| 🥈 2 | 经典黄金坑 | 突破 H2 + 回踩趋势线 |
| 🥉 3 | 黄金坑 | 回踩趋势线，尚未突破 H2 |
| 4 | 三主升 | 已进入主升浪 |
| 5 | 试盘突破 | 即将突破 H2 |
| 6 | 试盘试探 | 第一次攻击 H2 |
| 7 | 二回洗盘 | 第二次回踩 |
| 8 | 一涨完成 | 第一波上涨结束 |
| 9 | 主升结束回落 | 主升结束，淘汰 |

---

### 阶段判定优先级（由高到低）

1. 🔻 主升结束回落（淘汰）
2. 🏆 金标：突破 H2★ 回踩紫线 + 筹码峰合一（最高优先级）
3. 🏆 经典黄金坑买点 ★（高优先级）
4. 📈 三主升阶段（已经进入主升，不属于低吸）
5. 💰 黄金坑买点（中优先级）
6. 🚀 试盘突破
7. 🛫 试盘试探
8. 🔄 二回洗盘
9. 📈 一涨完成


# 二、金标（Premium Buy）⭐⭐⭐⭐⭐

## 判定条件

- 已突破二高（H2）
- 回踩 MA60（紫线）
- MA5、MA10 双线合一
- 均线粘合度 < 5.5%
- 回踩幅度 ≥ 3%
- 非暴跌

### 对应代码

```python
is_premium_buy = (
    has_broken_h2
    and near_ma60
    and convergence < min_convergence
    and chip_dual_convergence
    and pullback_from_peak >= 3
    and not severe_decline
)
```

## 加分规则

| 项目 | 分数 |
|------|------|
| 金标 | +5 |
| 粘合度 <2% | +3 |
| 粘合度 <3% | +2 |
| 粘合度 <5% | +1 |
| 回踩均线 | +2 |
| 缩量且粘合<3% | +2 |
| 缩量 | +1 |
| MACD 红柱 | +1 |
| MACD 红柱增长 | +1 |
| 第一波涨幅 <200% | +1 |
| 涨停 | +1 |
| 连板 | +1 |

---

# 三、经典黄金坑（Classic Buy）⭐⭐⭐⭐

## 判定条件

- 已突破 H2
- 回踩 MA10~MA20
- 均线粘合 <5.5%
- 回踩幅度 ≥5%
- 非暴跌

### 对应代码

```python
is_classic_buy = (
    has_broken_h2
    and near_tl
    and convergence < min_convergence
    and pullback_from_peak >= 5
    and not severe_decline
)
```

### 加分

经典黄金坑：

```
+3 分
```

其它评分规则与金标一致。

---

# 四、黄金坑（Buy Point）⭐⭐⭐

## 判定条件

- 回踩 MA10~MA20
- 均线粘合
- 第二波未上涨超过 20%

### 对应代码

```python
is_buy_point = (
    near_tl
    and convergence < min_convergence
    and not has_rallied
)
```

| 对比项 | 金标 | 经典黄金坑 | 黄金坑 |

# 六、其它阶段说明

## ① 三主升

特点：

- MA5 > MA10 > MA20
- 创新高
- MACD 持续放大

属于右侧趋势。

---

## ② 试盘突破

特点：

- 接近 H2
- 缩量整理
- 即将突破

等待放量即可。

---

## ③ 试盘试探

特点：

- 第一次攻击 H2
- 尚未突破
- 成交量一般

继续观察。

---

## ④ 二回洗盘

特点：

- 第一波上涨结束
- 第二次回踩
- 均线开始收敛

黄金坑形成前夕。

---

## ⑤ 一涨完成

特点：

- 第一波上涨结束
- 尚未形成第二次回踩

继续等待。

---

## ⑥ 主升结束回落

特点：

- 大涨结束
- 跌破 MA20、MA60
- MACD 死叉
- 回撤越来越深

直接淘汰。

---

# 七、输出字段说明

| 字段 | 含义 |
|------|------|
| 粘合度 | MA5、MA10、MA20 平均距离 |
| 粘合标签 | 极强、强、中等、发散 |
| 趋势线 | 是否回踩 MA10~MA20 |
| 紫线 | 是否回踩 MA60 |
| 多头 | MA5 > MA10 > MA20 |
| 缩量 | 是否缩量 |
| 量变 | 最近五日成交量变化 |
| MACD | 红柱大小 |
| MACD 增长 | 红柱是否增长 |
| H2 | 第二高点 |
| 距 H2 | 当前距离 H2 百分比 |
| 回踩幅度 | 高点回撤百分比 |
| 筹码峰合一 | MA5、MA10、MA20 是否粘合 |
| 双线合一 | MA5≈MA10 |
| 一涨涨幅 | 第一波涨幅 |
| N 字有效 | 是否满足 N 字结构 |

# 十、一句话总结

黄金坑选股器的核心逻辑可以概括为：

```text
N 字结构
    ↓
是否突破 H2
    ↓
回踩位置（MA60 或 MA10~20）
    ↓
均线粘合
    ↓
筹码峰合一
    ↓
最终评分
```

其中：

- 🏆 **金标**：突破 H2 + 回踩 MA60 + 双线合一，确定性最高，适合重仓。
- 🏆 **经典黄金坑**：突破 H2 + 回踩 MA10~20，适合标准仓位。
- 💰 **黄金坑**：尚未突破 H2，但进入回踩阶段，适合提前试仓。
