       这个skill主要是为了筛选出在我认为是止跌信号的股票中，放量上涨的股票。
       这个skill的逻辑是：在股票下跌过程中，出现一根止跌的阳线，这个止跌的k线符合：开盘价小于昨日最低价，今日收盘价大于昨日的最低价；这天买进后，后期股价上涨同时，成交量在放大，量能放大，放心持股
### 分析指标
- 常用指标
    - obv
    - rsi--金叉上升30+
    - cci--上升30+
    - kdj--金叉
    - macd--金叉

- 筹码指标
   
    无延迟筹码三大核心指标
    - 双线合一：确定主力高度控盘的区间
    - 四点共振：进准阻力主力上升的起爆点
    - 锁仓破仓：提高交易的成功率

    **口诀：锁仓看抛压，破仓看承接**

    正常流程：主力建仓->洗盘-> 试盘 -> 拉升；
    
    <span style="color: red;">我们的买点在试盘之后的三线合一位置或四点共振位置</span>
